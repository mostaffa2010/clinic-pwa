# PhysioCare - إدارة عيادة العلاج الطبيعي والتأهيل (PWA)

تطبيق متكامل وتفاعلي لإدارة عيادات ومراكز العلاج الطبيعي، مصمم بتقنيات الويب الحديثة (HTML5, CSS3, Vanilla JavaScript ES Modules) كـ Progressive Web App (PWA).

## المميزات الرئيسية
1. **سجل المرضى الكامل:** تسجيل المرضى الجدد والحاليين (الاسم، السن، الهاتف، العنوان، الطبيب المعالج، نظام المحاسبة: نقدي أو شركات تأمين بتعاقد مباشر/غير مباشر).
2. **تسجيل الجلسات اليومية:** تحديد المريض، الطبيب، والأعضاء المعالجة في الجلسة (الرقبة، أسفل الظهر، الركبة، الكتف، الكاحل...) والمبالغ المقبوضة.
3. **التقرير اليومي والحسابات:** إحصائية فورية لعدد المرضى، دخل العيادة النقدي، إجمالي المصروفات، صافي الدرج، وإحصائية بعدد مرضى كل طبيب.
4. **تصدير Excel وطباعة Wi-Fi:** تصدير شيت إكسيل منسق (.xlsx) بنقرة زر، وطباعة التقرير لاسلكياً بحجم A4 بهوية المركز.
5. **نظام الصلاحيات والرقابة:** مدير المركز (Admin)، أطباء (Doctors)، سكرتارية (Receptionist)، مع سجل تدقيق كامل لكل تعديل (Audit Trail).
